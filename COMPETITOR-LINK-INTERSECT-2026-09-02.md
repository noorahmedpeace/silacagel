## 7. Getting the complete picture with free Ahrefs tools (30 minutes, do once)

This file came from web search. Ahrefs sees links that search does not. Without a paid plan, do this:

1. **Ahrefs Webmaster Tools** (free, verify drygelworld.com via GSC): Site Explorer → Backlinks → filter **Dofollow** → export. This is the true list of the ~27 counting domains. Sort by DR; any nofollow link from a DR 40+ domain goes to the "ask to make followed" list.
2. **Free Backlink Checker** (ahrefs.com/backlink-checker) for each competitor domain: absortech.com, desiccare.com, multisorb.com, wisesorbent.com, sorbentsystems.com, streampeak.com.sg, topsorb-desiccant (find exact domain), micropakltd.com, hydrosorbent.com (dehumidify.com).
